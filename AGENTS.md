# Agent Operational Rules & Conventions

## Git Commit & Push Workflow
- **Individual File Pushes**: Always stage, commit, and push files individually one by one. Never batch multiple files into a single commit.
- **Commit Messages**: Each commit must have a clear, descriptive message specific to the single file being committed.

## Code & UI Guidelines
- **No Comments**: Do not write comments in code. Maintain existing comments without adding new ones.
- **No Emojis**: Do not include emojis in code or UI text.
- **Color Palette & Styling**: Exclusively Tailwind CSS and DaisyUI using the Midnight Navy / Neon Teal design system (#0B1220, #00D6B4, #243247, #172638).
